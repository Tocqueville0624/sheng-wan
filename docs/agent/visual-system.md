# Visual system

Preserve the academic-first layout: warm white pages, Newsreader headings, Inter body text, and dark blue readable copy. Prefer compact spacing and serif sentence-case labels over all-caps tracked eyebrows. Do not restore SW badges, decorative heading dashes, capsule buttons, or status pills. Controls use subtly rounded rectangles; research status is plain text.

The user's visual reference informs only the palette and open-sky mood. Do not publish the reference image or reproduce its album lettering, portrait, artwork, or composition.

Hand-painted ivory and slate-blue gulls are shared through `src/components/DoveMark.astro`, using the transparent local WebP in `public/media/decorative/`. The user prefers simplified painted shapes and visible brushwork, not photographic feathers or geometric bird icons. Reference images inform the airy palette and printed mood, not an album composition; see `seagulls-asset.md` for generation, anatomy review, and alpha-extraction provenance. They are static, decorative (`aria-hidden`, `focusable=false`), and non-interactive. Use them sparingly on the Home portrait, Hugo photo wall, footer, and 404. Never overlay research/CV text, charts, or faces. `.sky-surface` uses the user-requested blue-white sky gradient and local static grain; portraits use thick warm-white Polaroid borders, not heavily rounded frames. Home's paper frame stays straight; only Hugo's casual photo wall uses rotations.

Header and footer share a quiet blue ground. The wordmark is “Sheng Wan | Political Science”, with both parts at the same responsive font size. The body and its flex page surface have a `calc(100dvh + 28px)` minimum height, giving short pages a small native scroll range while keeping the footer at the document end. On every page, the main track absorbs unused viewport height while the footer remains in normal flow at its intrinsic compact height; never stretch the footer to fill sparse pages or fix it to the viewport. Root/body backgrounds use the same `--sky-footer` color as the bars; `.site-page` keeps `--background`, so exposed extensions match in either theme without tinting page content.

In-range scrolling is browser-owned. At the actual top or bottom boundary, the site supplies the visible elastic continuation requested by the user because the in-app browser did not expose native elasticity reliably. Keep the permanent `.site-page-clip { overflow: clip }` geometry boundary and transform only `.site-page`; never transform root/body or change document height. Resisted movement is directly coupled to active wheel or touch input, capped at 56 px; do not chase each packet with a spring because that creates perceptible lag and excessive exposed footer canvas. Coalesce drag writes to at most one animation frame and cache gesture geometry/control checks. Once quiet or declining-tail intent confirms release, switch exactly once to a browser-native Web Animations tween: 140–180 ms by distance, cubic-bezier(0.25, 0, 0.35, 1), monotonically to zero without overshoot or rebound. Genuine reverse input during return immediately cancels the transform and hands its full delta back to in-range scrolling. Wheel quiet time adapts between 110–180 ms. After release, same-direction residual packets stay locked out for 240 ms unless they return to at least 82% of the gesture peak and clearly strengthen over the preceding packet; a genuine later gesture starts normally. This prevents noisy trackpad inertia from recapturing the page and producing vertical shake without breaking repeat gestures. Promote the page only while active and remove the transform, state attributes, and `will-change` after settlement.

The boundary controller must remain fail-closed. Reduced motion, zoom, no JavaScript, dialogs/popovers, nested scroll regions, controls, modified/horizontal wheel input, non-cancelable touch, keyboard, focus, anchors, visibility and navigation retain native ownership or synchronously clear the effect. A captured touch may manually hand its exact cross-zero remainder into in-range scrolling until that touch ends; no frame may combine an interior document position with a residual page transform. Root/body/clip backgrounds use `--sky-footer`, so exposed top and bottom pixels match the bars in both themes. Historical review records remain local-only; the current behavior is covered by the checked-in browser and unit tests.

Reduced motion disables the boundary enhancement, smooth anchor scrolling and transitions. The historical archive remains script-free and uses the same minimum-height rule. Research item separators sit below each item. Contact links use accessible icons; Home prefixes them with “Contact Me:”. Playground is a native-popover dropdown (desktop hover and keyboard/touch activation), not an overview destination; its legacy URL redirects to Thales’ Olive.

Gallery photographs have no visible numeric badges and use a compact full-aspect justified layout. The focus dialog constrains each image to both the available width and height, preserving its full aspect ratio, including portraits and landscape-oriented phones. Avoid auto-sized picture grid tracks, clipped placeholders and arrows over the photograph. While the native focus dialog is open, CSS locks root overflow; a stable scrollbar gutter on Gallery prevents width shifts. Never replace that local modal lock with global input interception or a fixed/transformed body. The metadata panel can still scroll on short screens and has an explicit keyboard focus target. Hugo's carrier photo stays uncropped; only the sofa photo has the user-approved tighter CSS crop. Keep source photographs intact.

Hugo's “Historical UW Profile” links to `/archive/hugo-uw-profile/`, a self-contained archived copy of the original complete UW profile text and portrait. Keep its source URL, capture timestamp, archive disclaimer, and `provenance.json` integrity hashes. Do not silently refresh historical content or add external assets, scripts, trackers, or unrelated UW pages.

Theme colors are defined in `src/styles/global.css`. New accents must work in light and dark modes. Test Home and 404 at 320, 390, 840, 841, and 1440 px without global overflow hiding. Preserve readable text contrast, especially on the blue footer.
